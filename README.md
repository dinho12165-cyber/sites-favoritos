# 🌐 Meus Sites Favoritos

Este é um projeto simples de desenvolvimento web que reúne e organiza os meus sites mais acessados no dia a dia. O objetivo principal foi praticar a estruturação de elementos em HTML5, manipulação de links, quebras de linha e renderização de imagens vetoriais (SVG) diretamente no navegador.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Para a estruturação e organização do conteúdo da página.
* **SVG (Scalable Vector Graphics):** Para renderização dos logos oficiais de forma leve, rápida e sem dependência de servidores externos.
* **VS Code:** Editor de código utilizado para o desenvolvimento.

## 📌 Sites Adicionados

* **GitHub:** Plataforma de hospedagem de código e controle de versão.
* **Canva:** Ferramenta de design gráfico online.
* **ChatGPT:** Assistente de inteligência artificial para produtividade e estudos.
* **WWF:** Organização não governamental internacional para a conservação da natureza.
* **iLovePDF:** Ferramenta online e gratuita para modificação e gerenciamento de arquivos PDF.

## 📋 Requisitos do Exercício Atendidos

- [x] Extensão do arquivo convertida corretamente de `.py` para `.html`.
- [x] Inclusão do nome do aluno no título da aba (`<title>`) e no cabeçalho principal (`<h1>`).
- [x] Nome de cada site posicionado **acima** da imagem correspondente (`<h3>`).
- [x] Link de acesso configurado **abaixo** de cada imagem (`<a>`), abrindo em uma nova aba (`target="_blank"`).
